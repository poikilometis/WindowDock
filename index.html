Your open windows in one workspace.

Collect the Codex, Claude Code and desktop app windows you already have open. Keep them visible in grids and switch between projects in named tabs.

Download for Windows x64

Portable ZIP on GitHub · Free and open source

Keep parallel work in view

Collect what’s running
Add open terminals, editors and other apps. Move or minimize the workspace as a group while each application keeps running.
Give each project a tab
Keep several sessions visible in a grid. Double-click a panel header to give one window more room, then return to the grid.
Go straight to the prompt
Optional hooks show which Codex, Claude Code or Gemini CLI session needs attention. A Windows notification can take you to its panel.

Try it with two open terminals

Get the -win-x64.zip asset from the latest release, extract the full archive, and launch WindowDock.exe. Choose Add windows to pick your terminals.

The ZIP includes .NET. Start with WindowDock and your terminals running at the same Windows privilege level.
