# Code of conduct

Treat contributors and users with respect. Discuss the work, give actionable feedback, and welcome people of different backgrounds and experience levels.

Harassment, threats, discrimination, personal attacks, sharing private information without consent, and deliberate disruption are not acceptable in project issues, pull requests, and discussions.

Maintainers may edit or remove harmful content, close discussions, restrict participation, or block accounts. Enforcement should be proportionate and explainable. GitHub's reporting tools are available for abuse; use private vulnerability reporting for security issues as described in [SECURITY.md](SECURITY.md). Do not post personal information or sensitive evidence publicly.
